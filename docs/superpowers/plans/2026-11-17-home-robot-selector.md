# 홈의 로봇 선택 표시 수정

시각 기준: 사용자가 첨부한 홈 화면 이미지. Figma Page 5를 읽었다고 간주하지 않는다.

- 인사 → 미확인 알림 → 로봇 1·2 선택 버튼과 우측 로봇 목록 링크 → 선택한 로봇 상태 카드 순서.
- 실제 서버에서는 GET /robots의 배정된 로봇만 표시. ID로 선택을 유지하고 이름 변경 후 홈 복귀 시 갱신.
- 서버 없는 목업은 기본 2대 예시 제공. 계정별 robots가 지정되어 있으면 빈 목록도 그대로 반영.
- 실제 배터리 비율은 아직 없으므로 임의 계산하지 않고 수신된 전압(V) 또는 미수신 표시.
- 수신하지 않은 칸별 적재율은 빈 카드를 표시하지 않음.
- 기존 목업의 단일 경로 설정은 첫 번째 로봇에서 유지. 두 번째 로봇 경로와 분리.

리뷰: 홈의 실제 데이터 매핑·ID 선택·복귀 갱신에 중요 결함 없음. 빈 적재율 카드와 구 목업 경로 호환성은 추가 수정.
실제 DB 읽기 확인: 2026-11-17 현재 robots 행 0개. UI 작업 중 가짜 로봇 등록·배정은 하지 않음.
