# 앱·총관리자 웹·서버 분리

사용자 요청: app/는 하위관리자 앱, web/은 총관리자 웹, server/는 공통 API로 분리한다.

기존 Figma W-02 디자인과 API를 React·TypeScript·Vite 독립 웹으로 이관한다. web/은 app/ 소스나 node_modules를 참조하지 않는다. 기존 Bearer JWT 방식을 유지하며 쿠키 전환은 이번 범위에 포함하지 않는다.

- [x] 앱에서 총관리자 로그인은 웹 로그인 안내 후 토큰을 보관하지 않는다.
- [x] web/ 전용 로그인은 총관리자만 허용한다.
- [x] 화면·API·훅·전용 자산·테스트를 web/로 이관하고 app/의 총관리자 경로를 제거한다.
- [x] 서로 다른 앱·웹 세션으로 가입→승인→모바일 로그인→경로 저장→재로그인 실제 HTTP 검증.
- [x] 앱/웹/서버 검사·테스트·빌드 및 독립 실행 방법 문서화.

웹 5173 포트의 /api 프록시 → 공통 서버 8000 포트. 앱 Expo 웹은 모바일 화면 개발용으로 유지한다.

## 검증 결과
- 앱 check 통과(기존 경고 4개), 앱 테스트 11개 통과.
- 웹 check, 테스트 6개, 독립 프로덕션 빌드 통과. 의존성 설치·빌드는 app/의 node_modules나 소스를 사용하지 않는다.
- 서버 Ruff check 및 소스 디렉터리 format 검사, 전체 테스트 101개 통과.
- 실제 앱 API와 독립 웹 API의 각 메모리 세션을 사용하는 로컬 HTTP + 격리 DB 검증 통과. 총관리자의 앱 로그인 거부, 하위관리자의 웹 로그인 거부, 서버의 권한 거부도 확인했다.
- localhost:5173 개발 서버를 실행하고 /, /src/main.tsx, 원본 아이콘, /api/health가 200 응답함을 확인했다.
- 공유 Supabase의 계정·운영 데이터는 변경하지 않았다. 브라우저 호스트 연결 제한으로 실제 클릭·스크린샷 검증은 수행하지 못했다.
