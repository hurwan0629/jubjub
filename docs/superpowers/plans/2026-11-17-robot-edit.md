# 로봇 목록과 편집 연결

사용자 요청: Figma Page 5의 다중 로봇 화면, 목록의 버튼을 '편집'으로 변경하고 로봇별 경로 편집 및 이름 수정 연결.

현재 제약: Figma MCP View seat 사용 한도로 Page 5 metadata/design context를 읽지 못함. 화면 디자인 일치 검증은 미완료이며 임의로 완료 처리하지 않는다. 먼저 명시된 기능을 기존 앱 컴포넌트와 스타일로 구현한다.

- [x] 이름 변경 서버 API: 승인된 내 공원에 배정된 로봇만 변경 가능, 이름 유효성 검사, 경로·시간표 보존.
- [x] 앱 API 및 로봇 목록: 로봇별 '편집' 진입, 선택한 로봇 ID 유지.
- [x] 로봇 편집: 이름 변경 및 경로 편집 메뉴, 서버 실패 표시.
- [x] 기존 경로 편집에서 전달받은 로봇 선택, 목록 복귀 시 이름 갱신.
- [ ] 서버·앱 회귀 검사. Page 5 실제 디자인 대조는 접근 제한 해제 후 진행.
