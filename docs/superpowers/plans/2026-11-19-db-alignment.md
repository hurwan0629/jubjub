# 현재 DB 명세 정합성 수정 계획

**Goal:** Confluence 현재 DB 23판의 확정된 테이블 변경과 API 계약을 반영해요.
**Architecture:** 기존 0012 다음에 데이터 이전용 0013을 추가해요. 순찰 지점과 분리수거장 저장을 분리하고 공원 처리 기록을 통일해요.
**Tech Stack:** FastAPI, SQLAlchemy, Alembic, PostgreSQL, React Native, React.
**Spec:** https://kdt-3team-finalterm.atlassian.net/wiki/pages/7471105 (v23).

## 제약
- 기존 미커밋 변경을 보존하고 현재 dev 작업 공간에서 이어서 수정해요.
- 추가 예정 에이전트 테이블은 제외해요. 공유 DB 적용과 코드 검증은 구분해요.
- 옛 반려의 실제 처리자·시각을 추측해서 만들지 않아요.

## 작업
- [ ] 승인·반려·취소·재신청의 reviewedBy/reviewedAt 회귀 테스트를 먼저 실행하고 모델·서비스·응답을 수정해요.
- [ ] 경로 저장 시 순찰 지점만 생성되는 테스트를 실행하고 points.type과 routes.station_id 의존성을 제거해요.
- [ ] 충전 상태를 DB와 API에서 거부하는 테스트를 실행하고 앱·웹 상태 타입과 표시를 맞춰요.
- [ ] 0013에서 기존 분리수거장 참조를 이전하고 레거시 열을 제거해요. PostgreSQL 트랜잭션 테스트로 이력·중복 좌표·롤백을 검증해요.
- [ ] API 문서와 생성 명세를 갱신하고 서버 전체 테스트·린트·앱/웹 테스트와 타입 검사를 실행해요.

## 검토 초점
- 분리수거장 ID와 points ID가 같아도 다른 장소일 수 있어 좌표·공원 기준으로 이전해요.
- 이미 default_station_id가 있는 경로는 해당 참조를 유지해요.
- 과거 비활성 경로와 소프트 삭제된 분리수거장 참조도 보존해요.
- 기존 반려 이력은 처리자·시각을 알 수 없으므로 빈 값 쌍을 유지하고, 새 처리부터 두 값을 기록해요.
- 예상하지 못한 charger/bin 또는 비순찰 route_points는 이전 전에 오류를 내어 데이터 손실을 막아요.

## 진행 기록
- 사용자가 제안된 범위와 즉시 작업을 승인했어요. 기존 작업과 연결되어 있어 별도 worktree/커밋 없이 현재 공간에서 수정해요.
- 테이블·서비스·API 응답·앱/웹 상태 타입 수정과 문서 재생성을 완료했어요.
- 신규 회귀 테스트의 실패를 먼저 확인한 뒤 수정했어요. 서버 전체 189개 통과, DB 연결을 요구하는 기본 스킵 7개예요. 신규 PostgreSQL 이전 테스트 2개는 별도 실행으로 통과했어요.
- 독립 코드 리뷰에서 중요 문제나 경미한 지적이 없었어요. 추가 점검 중 앱 경로 저장에서 defaultStationId가 빠지는 문제를 회귀 테스트로 확인하고 수정했어요.
- 실제 DB의 0012 상태와 장애 데이터 부재를 확인한 뒤 로컬 백업을 저장하고 0013을 적용했어요. 순찰 지점 16개, 경로 9개, 공원 5개, 로봇 22개와 기존 참조를 검증했어요.
- `alembic check`에서 추가 변경이 없고 서버 린트·포맷 검사가 통과했어요.
