# 로봇별 순찰 설정 작업 계획

사용자가 승인한 범위: 공원당 여러 로봇의 경로·시간표 분리, 순찰 지점 삭제 범위 제한, 공용 분리수거장 이동 시 전체 경로 버전 갱신.

## 설계
- 공용 분리수거장은 공원당 하나. 경로·시간표에 robot_id를 추가한다.
- 로봇이 없을 때 기존 초기 설정을 유지하기 위해 robot_id NULL은 공원의 미배정 초안으로 보존한다. 로봇이 하나면 생략 시 자동 선택, 여러 대면 명시적 robotId가 필요하다.
- 기존 공원 공용 설정은 배정된 각 로봇에 복제한다. 순찰 지점은 로봇 간 공유하지 않는다. 로봇이 없는 공원 설정은 초안으로 남긴다.
- API는 robotId 쿼리로 조회·저장하며 응답에도 대상을 명시한다. 다른 공원/미배정 로봇은 거부한다.
- 분리수거장 변경은 모든 활성 경로를 먼저 검증하고 단일 트랜잭션으로 새 버전을 만든다.
- 기존 앱의 초기 설정/편집 화면에 로봇 선택을 추가한다.
- 실제 로봇 실행·SLAM 변환 및 실시간 상태 컬럼은 이번 범위에 포함하지 않는다.
