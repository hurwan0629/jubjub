# Page 4 화면 수정

사용자가 제공한 전체 화면 구성 및 승인 취소 상세 캡처를 기준으로 기존 React 웹을 수정한다. 별도 디자인 제안 없이 제공된 구성을 따른다. 축소 캡처에서 읽히지 않는 세부 수치는 일치한다고 주장하지 않는다.

- [x] 홈: 실제 관리자·로봇 상태 요약, 운영 목록, 가입·공원 변경 승인 대기 바로가기.
- [x] 관리자 보기: 가입 승인 / 공원 변경 승인 탭, 상태 필터, 검색, 10개 단위 페이지 이동.
- [x] 공통 페이지 이동: 필터 변경 시 초기화, 데이터 감소 시 마지막 유효 페이지로 보정.
- [x] 가입 승인·반려·취소 및 공원 변경 승인·반려: 중앙 모달, 본문 스크롤, 긴 내용 줄바꿈, 사유 입력. 공원 변경 상세는 추가 제공된 이미지의 두 공원 카드 및 주황색 안내·승인 버튼 적용.
- [x] 보고: 목록 배너와 페이지 이동, 상세의 요약/차트/이벤트 3열과 날짜 선택.
- [x] 로봇: 동일한 행 버튼 및 배정 모달, 등록 폼 접기, 검색·페이지 이동. 배정 검색창과 목록 스크롤 영역 분리.
- [x] 검증: 테스트 11개, 타입·포맷 검사, production 빌드 통과.
- [ ] 브라우저 화면 확인: 사용자 Escape 입력으로 컴퓨터 제어 중단. 시각 일치 검증은 미완료.

관리자 보기 아이콘 기본 stroke를 다른 메뉴와 같은 회색으로 수정. 선택 시 기존 CSS로 흰색 표시.
