# R2 사진 연동

기존 대화에서 승인한 FastAPI 업로드 → 비공개 R2 → DB 파일 경로 → 권한 확인 후 서명 URL 방식을 구현해요. 직접 업로드용 공개 URL 대신 서버에서 크기와 이미지 형식을 검사해요.

- [x] 기존 detections.image_path에 R2 객체 키를 저장하는 사진 API 테스트를 먼저 작성하고 실패를 확인해요.
- [x] R2 설정·boto3 저장소·탐지 사진 업로드/조회 API를 구현해요. 승인된 담당 공원만 접근하고, 사진은 5MiB 이하 JPEG/PNG, URL은 600초로 제한해요.
- [x] 외부 저장 실패 및 DB 실패 시 이전 경로를 보존하고 신규 파일을 정리해요. 키·서명 URL을 로그에 출력하지 않아요.
- [x] 전체 서버 테스트·ruff 검사와 작은 임시 파일을 이용한 실제 R2 업로드/읽기/삭제를 검증해요. 실제 DB 데이터는 변경하지 않아요.
- [x] 서버 사용 문서와 환경 변수 예시를 갱신해요. 새 탐지 생성·로봇 인증 및 앱 화면 연결은 기존 후속 작업이며 이번에는 기존 탐지의 사진 API를 제공해요.
