## 1. 개발 목표와 단계별 MVP

**최종 목표:** 로봇이 이동하면서 쓰레기를 탐색 → 인식·분류 → 위치 추정 → 접근 → 집기 → 후면 수거통 적재 → 종류별 배출한다.

| 단계 | 구현 범위 | 완료 판단 |
| --- | --- | --- |
| M0: 오프라인 인식 | 이미지·영상의 탐지/분류, 가상 제어(Mock) 연결 | 데이터·모델 버전 및 평가 결과 재현 가능 |
| M1: 실제 로봇 접근 | 카메라 입력 → 대상 선택 → 이동·방향 조절 → 안전 정지 | 사람이 감시하는 제한 환경에서 반복 재현 |
| M2: 그리퍼 수거 | 파지→이송→수거통 적재 | 물체별 집기/적재 성공률 측정 |
| M3: 자율 통합 | 탐색부터 분리배출까지 반복 수행 | 단계별 및 종단 간 성공률·처리 시간 측정 |

- 초기 클래스 후보: `plastic`, `can`, `paper`, `general`(공용 `vision/README.md`의 초안). 최종 라벨 정의는 데이터 확인 후 결정.
- **`unknown`/보류는 `general`과 구분**한다. 비대상 물체나 신뢰도가 낮은 탐지는 수거 명령으로 연결하지 않는다.
- 위험한 폐기물(유리 파편, 날카로운 금속, 새는 액체 등)은 초기 자동 집기에서 제외한다.
- 그리퍼 도착 전에는 **M1 성공**을 독립적인 시연 결과로 인정한다.

추가 과제:
- TACO(실외 쓰레기 탐지)·TrashNet(이미지 분류 위주) 등의 **라벨 형식·용도·라이선스** 검토.
- 유사한 영상 프레임이 학습/검증에 동시에 들어가지 않게 **장소·장면 기준 데이터 분리**. 다른 조명, 거리, 가림, 배경으로 테스트.
- 학습 설정(seed, 모델 버전, 데이터 분할, 하이퍼파라미터) 및 오탐/미탐 샘플 기록.
- CNN 직접 구현보다 **학습/평가 가능한 소형 탐지 베이스라인**을 우선.
- 이미지 bbox는 2D 픽셀 좌표이며, **로봇 기준 거리·3D 좌표와 다름**을 설계에 반영.

## 4. 제어·AI 아키텍처 초안

```text
Camera / Recorded Video
  → Detector [class, bbox, confidence, timestamp]
  → Target Selector [선택/보류, target ID]
  → Relative Pose Estimator [방향, 거리, 신뢰도]
  → Behavior Controller [SEARCH → ALIGN → APPROACH → VERIFY]
  → ROS Control [실물 로봇 / Mock]
  → Logger & Safety Monitor
  → (그리퍼 추가 후) GRASP → LOAD → SORT
```

- **객체 탐지:** YOLO 계열 경량 모델로 기준선부터 구축.
- **위치 추정:** 카메라 내부 파라미터·설치 방향·깊이/거리 센서를 확인하고 측정 오차를 검증. bbox 하나만으로 정확한 거리를 결정하지 않음.
- **동작 계획:** 우선 상태 머신(FSM)과 규칙 기반. 짧은 이동 → 재관측 → 수정의 폐루프 제어.
- **시계열:** 연속 프레임에서 대상이 흔들리면 객체 추적·confidence 평활화부터 사용. LSTM/Transformer는 필요성 확인 후.
- **SLAM:** 실내 모형/통제된 구역에서 탐색·접근이 가능한지 먼저 확인하고, 자율 탐색의 병목이 될 때 검토.
- **강화학습:** 초기 범위에 넣지 않음. 그리퍼 조작 등에서 규칙 기반 한계가 나타나고 시뮬레이션·보상 설계·안전 검증이 확보되면 비교.
- **VLM:** 모호한 쓰레기 분류에 보조적으로 검토하되 단독으로 위험한 이동/집기 명령을 결정하지 않음.
- **토픽 예시:** `/camera/image_raw`, `/trash/detections`, `/trash/target`, `/trash/behavior_state`, `/cmd_vel`은 *가상 계약 예시*일 뿐, JetHexa 실제 인터페이스로 확정하지 않는다.

## 5. 테스트·평가 계획

| 구간 | 지표 | 테스트 및 가설 목표 |
| --- | --- | --- |
| 탐지 | mAP@50, 클래스별 Precision/Recall, 오탐/미탐 | 독립 테스트셋; 초기 가설 mAP@50 ≥ 0.80 (데이터 확인 후 재설정) |
| 보류 판단 | 비대상 물체에 대한 잘못된 접근 횟수 | `unknown`/저신뢰도에서 접근 금지 |
| 추론 | FPS, 평균·p95 지연, 메모리 사용량 | PC/Jetson 각 실측, 로봇 속도에 맞춰 허용 지연 결정 |
| 거리·위치 | 방향 오차(°), 거리 오차(cm) | 여러 거리/각도에서 줄자와 비교 |
| 접근 | 목표 근처 정지율, 충돌/실패 횟수 | 안전 구역에서 10~20회 이상 반복 |
| 집기(추후) | 파지 성공률, 낙하율, 적재 성공률 | 물체 종류·크기·방향별 반복 |
| 전체(추후) | 발견→배출 성공률, 한 개당 처리 시간 | 구간별 실패를 구분해 집계 |

**테스트 단계**
1. 오프라인 단위 테스트: bbox/좌표 변환·임계값·unknown 처리.
2. 영상 리플레이: 동일 영상으로 재현성, 오탐, 추론 지연 검증.
3. Mock 통합: 메시지 지연·유실, 명령 타임아웃, 실패 상태 전이 확인.
4. 실물 제한 테스트: 장애물 없는 안전구역, 저속·짧은 이동, 감시자와 수동 정지.
5. 반복 시나리오: 조명·배경·물체 변경, 구간별 성공률과 실패 원인 추적.

로그: 실험 ID, 날짜, 장소·조명, 데이터/모델 버전, 목표 클래스·score, 거리, 추론/제어 지연, 행동 상태, 성공 여부, 실패 원인. 사람 얼굴·개인정보가 담긴 영상 취급 주의.
