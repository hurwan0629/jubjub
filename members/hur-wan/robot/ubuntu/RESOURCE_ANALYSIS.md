## 디스크 전체 이미지로 받을 때

- 물리 NVMe `/dev/nvme0n1`의 용량은 **128,035,676,160바이트(119.24 GiB)**다. 디스크 전체를 원시 복사하면 루트 파티션의 사용량 58G와 무관하게 이 크기의 데이터를 읽는다. 파티션 테이블, 부팅 파티션, 스왑 파일, 미할당 영역도 포함된다. 압축 후 크기는 실제 데이터 패턴에 따라 달라진다.
- 로봇의 루트 여유 공간은 4.5G이므로 이미지 파일을 로봇 안에 만들 수 없다. 받는다면 PC나 외부 저장장치로 직접 전송해야 한다.
- 실행 중인 시스템의 원시 이미지는 파일들이 서로 다른 시점에 기록될 수 있다. 복구 가능한 백업이 목적이라면 정지·오프라인 상태에서 이미징하고, 완료 후 해시와 마운트/복구 가능 여부를 확인하는 편이 안전하다.
- 전체 이미지에는 Wi-Fi 설정, SSH 키, 사용자 파일, 모델 가중치 등 기기별 정보가 들어갈 수 있다. 저장 위치와 암호화를 고려해야 한다.
- 다른 Jetson이나 다른 크기의 저장장치에 복원할 때는 부팅 구성과 장치 호환성을 별도로 확인해야 한다. x86 PC에서 Jetson OS 이미지를 그대로 실행하는 용도와는 다르다.
