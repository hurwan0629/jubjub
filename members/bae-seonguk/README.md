# 배성욱 (bae-seonguk)

- 담당: 관리자 앱·웹 화면 및 API 서버 연동
- GitHub: @BaeSungUk

공원 관리자가 앱으로 로봇의 순찰을 설정하고, 총관리자가 웹에서 가입·공원 변경·로봇 배정을 관리할 수 있도록 작업했습니다.

## 작업한 기능

- **관리자 앱**: 회원가입·로그인, 공원 변경 신청, 로봇 목록·정보 수정, 로봇별 순찰 경로·시간 설정.
- **총관리자 웹**: 홈 운영 현황과 승인 대기 인원, 가입 승인·반려·취소, 공원 변경 승인·반려, 공원별 일일 보고, 로봇 등록·배정 변경.
- **화면 개선**: Figma와 제공된 화면을 참고해 메뉴·팝업·버튼을 정리하고, 목록 검색·페이지 이동을 추가했습니다.
- **서버·DB**: 화면을 실제 API와 연결하고, 로그인 권한 확인과 승인 처리, 로봇별 순찰 데이터 저장을 구현했습니다.

## 사용한 기술

| 구분 | 사용 기술 |
| --- | --- |
| 모바일 앱 (`app/`) | Expo, React Native, TypeScript |
| 관리자 웹 (`web/`) | React, TypeScript, Vite |
| API 서버 (`server/`) | Python, FastAPI, SQLAlchemy |
| 데이터베이스 | Supabase PostgreSQL, Alembic(테이블 변경 관리) |
| 디자인·개발 도구 | Figma, Codex, Git·GitHub |
| 검증 | Node.js 테스트, pytest, 타입·포맷 검사, 웹 빌드 |

실행 방법은 [앱](../../app/README.md), [웹](../../web/README.md), [서버](../../server/README.md) 문서를 참고하면 됩니다.
