# R2 사진 저장

서버 `.env`의 `R2_ACCOUNT_ID`, `R2_ENDPOINT`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET_NAME`을 사용해요. `R2_ENDPOINT`는 버킷 이름을 붙이지 않은 HTTPS S3 API 주소예요. 비어 있으면 account ID로 구성해요. 키에는 해당 버킷의 객체 읽기·쓰기·삭제 권한이 필요해요. 버킷은 비공개로 유지해요.

```powershell
cd server
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts/check_r2.py
```

연결 검사는 1픽셀 PNG를 업로드하고 서명 URL로 읽은 뒤 삭제해요. DB는 연결하지 않으며 R2 요청 사용량은 소량 집계돼요. 환경 변수를 바꾸었다면 실행 중인 FastAPI 서버를 재시작해요.

## 사진 API

기존 `detections` 행에 사진을 첨부하는 API예요. 탐지 이벤트 생성·로봇 수신 파이프라인 및 앱 화면 호출 연결은 별도예요. 아직 탐지 행이 없다면 먼저 로봇 탐지 수신 기능에서 생성해야 해요. 이번 변경은 DB 테이블이나 마이그레이션을 추가하지 않아요.

- `PUT /detections/{id}/photo`: Bearer 인증, `Content-Type: image/jpeg` 또는 `image/png`, 본문은 JSON/base64/multipart가 아닌 파일 원본 바이트예요. 기본 최대 5MiB(`PHOTO_MAX_BYTES`), 최대 2천만 픽셀이에요. 성공하면 `detectionId`, `imagePath`를 반환해요.
- `GET /detections/{id}/photo`: Bearer 인증, `{url, expiresIn:600}`을 반환해요. 앱에서 URL로 이미지를 표시해요. 만료되면 API를 다시 호출해요.

승인된 담당 공원의 탐지만 접근할 수 있어요. R2 경로는 `parks/{parkId}/detections/{id}/{UUID}.png` 형태로 서버에서 생성해요. DB의 `image_path`에는 경로만 저장하며 임시 URL이나 비밀 키는 저장하지 않아요. 서명 URL은 만료 전까지 링크를 가진 사람이 열 수 있으니 로그에 남기지 않아요.

이미 R2 사진이 연결된 탐지는 덮어쓰기를 거부해요(409). 로컬 경로·외부 URL은 R2 조회 주소로 바꾸지 않아요(404). 기존 로컬 사진은 자동 이전되지 않아요. R2 장애는 503으로 반환하며 DB 저장 실패 시 신규 파일을 삭제하려고 시도해요. 네트워크 장애로 정리에 실패하면 고아 파일이 남을 수 있어요.

예시(Python, 실제 탐지 ID와 JWT로 교체):

```python
from pathlib import Path
import requests

headers = {"Authorization": f"Bearer {token}", "Content-Type": "image/jpeg"}
response = requests.put(f"{api}/detections/{detection_id}/photo",
                        headers=headers, data=Path("photo.jpg").read_bytes(), timeout=30)
response.raise_for_status()
photo = requests.get(f"{api}/detections/{detection_id}/photo",
                     headers={"Authorization": f"Bearer {token}"}, timeout=15)
photo.raise_for_status()
```

파일당 제한은 전체 저장량·월 비용 상한이 아니에요. 총량 제한과 보관 기간별 삭제 정책은 별도 설정이 필요해요. 공개 버킷·Cloudflare Workers·CORS 정책은 이 서버 경유 방식의 필수 항목이 아니에요.

공식 참고: https://developers.cloudflare.com/r2/examples/aws/boto3/
