# vision

카메라 이미지로 공원 쓰레기를 찾고 종류를 분류하는 모델을 둡니다.

## 예정 구성
```
vision/
├─ train/       학습 스크립트, 설정
├─ inference/   로봇에서 돌릴 추론 코드
└─ configs/     클래스 정의, 하이퍼파라미터
```

## 분류 클래스 (초안, 확정 전)
| 클래스 | 예시 |
|--------|------|
| `plastic` | 페트병, 플라스틱 컵 |
| `can` | 캔 |
| `paper` | 종이컵, 종이 |
| `general` | 일반 쓰레기 |

## 규칙
- 학습한 가중치(`*.pt`, `*.onnx`, `*.engine`)는 git에 올리지 않습니다. 공유 드라이브에 두고 링크만 여기에 적습니다.
- Jetson Nano에서 돌아가야 하므로 경량 모델과 TensorRT 변환을 고려합니다.
